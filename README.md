# Personal Skills

A curated collection of my frequently used personal skills, prompts, and workflows.

Each skill is organized in its own directory with instructions, reusable configurations, and examples that can be plugged into AI coding assistants or daily development work.

## Purpose

- Centralize frequently used skills in one place
- Keep versions of prompts, rules, and configs consistent across projects and machines
- Easy to share and reuse

## Structure

```
personal-skills/
├── skill-name/
│   ├── SKILL.md        # Skill description and usage
│   └── ...             # Supporting files (scripts, templates, etc.)
└── README.md
```

## Usage

Browse each skill directory and follow the instructions in its `SKILL.md`. Feel free to copy or adapt anything useful for your own workflow.
